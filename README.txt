MATT RIFE FAN COMMUNITY WEBSITE STARTER

Preview: open index.html in a browser.
Admin editor: click “Open admin editor” at the bottom.
Enter your WhatsApp number in international format using digits only, e.g. 2348012345678.
Then save. Ticket and membership enquiry buttons will open a WhatsApp chat with a prefilled message.

IMPORTANT:
- This is a front-end prototype, not a live hosted site or secure backend.
- Edits are saved only in the same browser/device using local storage.
- The admin editor is not password protected. Do not use it for sensitive customer information.
- For a public launch, add secure server-side admin authentication, database, file storage, privacy policy,
  and appropriate ticketing/payment processing.
- Only publish show dates, ticket offers, membership benefits, branding and photos that you are authorized to use.
- Keep the site's affiliation/authorization statement accurate and transparent.
